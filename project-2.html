Battery detection automation cell

Logos01 S.R.L / Industrial Automation  ·  Software Developer  ·  6 months

Designed and commissioned an automated robotic cell for the detection, inspection, and handling of battery components in a manufacturing environment. The system combines industrial robotics, machine vision, and PLC-controlled automation to improve positioning accuracy, inspection reliability, and production throughput.

Developed the robot application for autonomous pick-and-place operations while integrating the conveyor system, industrial vision, and production equipment into a synchronized automation workflow. The vision system identifies battery positions in real time, allowing the robot to accurately locate, inspect, and manipulate parts without manual intervention.

Performed system integration, testing, calibration, and commissioning to validate robot motion, vision accuracy, and communication between all automation devices. The completed solution delivered a reliable, repeatable, and production-ready inspection process capable of continuous operation in an industrial manufacturing environment.
